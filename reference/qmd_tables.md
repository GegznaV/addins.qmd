# Insert Quarto/Pandoc Markdown tables

Insert examples of Quarto/Pandoc Markdown tables.

## Usage

``` r
qmd_table_style_md(context = rs_get_context())

qmd_table_style_md_alternative(context = rs_get_context())

qmd_table_style_multiline(context = rs_get_context())

qmd_table_style_multiline_no_colnames(context = rs_get_context())

qmd_table_style_simple(context = rs_get_context())

qmd_table_style_grid(context = rs_get_context())
```

## Arguments

- context:

  (class `document_context`)  
  Object with context of active RStudio document.
