# addins.qmd: RStudio Add-ins for Quarto Documents

Package \`addins.qmd\` contains RStudio add-ins to format Quarto
documents. The main purpose of this package is to help beginners learn
Quarto and Pandoc Markdown syntax faster and use keyboard shortcuts for
common authoring elements.
